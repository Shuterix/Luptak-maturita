==========================================
HOW TO USE IN MONGODB COMPASS:
==========================================

1. Open MongoDB Compass
2. Connect to your database
3. Navigate to the 'users' collection
4. Find the user document you want to update
5. Click the "Edit Document" button (pencil icon)
6. Find the 'unavailability' field
7. If it doesn't exist, click "+" to add a new field
8. Select the field type as "Object" or "Document"
9. Copy one of the unavailability objects above
10. Paste it into the field (you can paste the entire JSON object)
11. Click "Update" to save

ALTERNATIVE: Using MongoDB Shell
==========================================

db.users.updateOne(
  { _id: ObjectId("YOUR_USER_ID_HERE") },
  { $set: { 
    unavailability: {
      timezone: "UTC",
      monday: [{"start": "08:00", "end": "12:00"}],
      tuesday: [{"start": "08:00", "end": "12:00"}],
      wednesday: [{"start": "08:00", "end": "12:00"}],
      thursday: [{"start": "08:00", "end": "12:00"}],
      friday: [{"start": "08:00", "end": "12:00"}],
      saturday: [],
      sunday: []
    }
  }}
)

Replace "YOUR_USER_ID_HERE" with the actual ObjectId of the user.

==========================================
NOTES:
==========================================

- Time format is "HH:mm" (24-hour format)
- Empty arrays [] mean the student is available all day
- You can have multiple time windows per day
- Exceptions are optional and used for specific dates
- Timezone defaults to "UTC" but can be changed
